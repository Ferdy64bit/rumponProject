# Fishing Point - Roadmap Pengembangan Skripsi

## Tujuan

Menyelesaikan aplikasi Android **Fishing Point** berbasis **Java +
Android Studio** menggunakan **Google Maps API**, **Firebase**,
**OpenWeather API**, dan **Tidecheck API** hingga siap digunakan sebagai
bahan skripsi dan sidang.
