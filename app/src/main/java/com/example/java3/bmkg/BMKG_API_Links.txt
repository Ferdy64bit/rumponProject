Data bmkg Lengkap

format data : JSON
Polygon Peta Pembagian Wilayah Prakiraan: https://peta-maritim.bmkg.go.id/public_api/static/wilayah_perairan.json
Overview gelombang: https://peta-maritim.bmkg.go.id/public_api/overview/gelombang.json
Penjelasan parameter: 
Parameter
issued: Waktu publikasi atau rilis prakiraan oleh stasiun dalam UTC (format YYYY-MM-DD hh:mm)
valid_from: Waktu awal berlakunya prakiraan (format YYYY-MM-DD hh:mm)
valid_to: Waktu akhir berlakunya prakiraan (format YYYY-MM-DD hh:mm)
time_desc: Deskripsi waktu (Hari ini, Besok, H+2, H+3)
weather: Kondisi cuaca (Cerah, Cerah Berawan, Berawan, Berawan Tebal, Asap, Kabut, Hujan Ringan, Hujan Sedang, Hujan Lebat, Hujan Lokal, Hujan Badai)
weather_desc: Deskripsi cuaca secara umum / Kondisi synoptik
warning_desc: Peringatan dini cuaca buruk
station_remark: Catatan tambahan dari stasiun
wave_cat: Kategori gelombang (Tenang, Rendah, Sedang, Tinggi, Sangat Tinggi, Ekstrem, Sangat Ekstrem)
wave_desc: Rentang rata-rata tinggi gelombang dalam meter
wind_from: Arah angin - dari (Utara ,Utara Timur Laut, Timur Laut, Timur Timur Laut, Timur, Timur Tenggara, Tenggara, Selatan Tenggara, Selatan, Selatan Barat Daya, Barat Daya, Barat Barat daya, Barat, Barat Barat Laut, Barat Laut, Utara Barat Laut)
wind_to: Arah angin - menuju (Utara ,Utara Timur Laut, Timur Laut, Timur Timur Laut, Timur, Timur Tenggara, Tenggara, Selatan Tenggara, Selatan, Selatan Barat Daya, Barat Daya, Barat Barat daya, Barat, Barat Barat Laut, Barat Laut, Utara Barat Laut)
wind_speed_min: Kecepatan minimum angin dalam satuan knot
wind_speed_max: Kecepatan maksimum angin dalam satuan knot
